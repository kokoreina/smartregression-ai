# UX research

Apply only to user research or usability acceptance criteria, not to infer algorithm
quality from a small UI study.

1. Read proposal NFRs and the current dashboard/report; distinguish committed
   requirements from proposed targets and implemented behavior.
2. Define participant profile, task, environment, observation, success rule, sample
   limitations, privacy handling and stopping condition before a session.
3. Prefer observable completion, errors, time and user explanation over satisfaction
   alone. Keep processing wait separate from active interaction where the requirement
   says so. Do not invent target values; trace each one to an approved source.
4. Record consent and minimize collected personal data. Do not put private repository
   content or participant identifiers in public prompts/reports.
5. Report raw observations separately from interpretation; identify sampling bias and
   unresolved questions. A usability result does not establish fault recall or safety.
