TEMPLATE - NOT RUN. No measured values. null means unknown; N/A requires a reason.
Source: [protocol](../evaluation-protocol.md). Mock product tests are not benchmarks.

| Required metadata | Value |
| --- | --- |
| Run/manifest/protocol revision, approval status | pending |
| Repository/license/base/target SHA/inventory hash/split | pending |
| Environment/tool/model/prompt/retrieval versions, seed, budget | pending |
| Method/baseline/fallback and initial-index accounting | pending |
| Frozen selection artifact/hash/time before execution | pending |
| Evaluator-only fault provenance and reviewer | pending |
| Commands/cwd/timestamps/exit status/redacted artifact references | pending |

| Metric | Numerator | Denominator | Value | Eligibility/N/A reason |
| --- | --- | --- | --- | --- |
| Planned/dispatched reduction | null | null | null | not run |
| Fault retention/missed fault rate | null | null | null | no adjudicated cohort |
| Impact precision/recall (symbol and module strata separately) | null | null | null | no independent labels |
| Time saving/overhead | null | null | null | not run |
| Valid-ID/evidence/fallback rates | null | null | null | not run |
| LLM usage/cost and indexing cost | null | null | null | not measured |

Report per-repo distributions, macro/micro, uncertainty/repeat policy, real/mutation
separately. Attempt ledger: each attempted run, eligibility, failed/excluded status,
timeout/flaky/infra classification and reason. Never silently drop failures.
Include protocol deviations, threats, leakage audit, missing artifacts and human
review. Leave conclusions pending. Declare actual AI tool/purpose/scope; no invented
signatures, approval or contribution percentages.
