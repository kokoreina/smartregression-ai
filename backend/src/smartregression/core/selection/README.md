# Selection — chưa triển khai

Chọn từ test inventory có stable framework IDs, validate membership và giải thích
selected/skipped/fallback. Input chỉ gồm change, evidence, inventory và policy cho phép.
Full-suite outcomes/fault labels chỉ thuộc evaluation, không vào selector.
Chưa định nghĩa interface rộng trước khi spike chốt framework và fallback policy.
